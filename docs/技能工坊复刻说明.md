# DAAgent 技能工坊复刻说明

本仓库新增了一个独立的、功能等价的本地技能工坊核心实现：

```text
servers/plugins/daagent/skill_workshop/
```

它基于已分析的 DAAgent 行为重新实现，没有修改 `D:\Program Files\DAAgent`，也没有复制 DAAgent 的安装目录文件。

## 已实现范围

- 技能目录扫描和 `SKILL.md` 检查
- 技能内容快照和 SHA-256 指纹
- SQLite 问题台账、提案和版本记录
- `SKILL.md`、`references/`、`templates/`、`scripts/`、`assets/` 补丁边界
- 按补丁接受或拒绝
- 临时目录测试，不改变正式技能
- 原子替换应用
- 派生新技能
- 版本族谱和回滚
- 独立 CLI

## 快速运行

在仓库根目录执行：

```powershell
$env:PYTHONPATH = (Join-Path (Get-Location) 'servers')
python -m plugins.daagent.skill_workshop --workspace D:\path\to\workspace list
```

创建提案所需的 JSON 文件格式：

```json
[
  {
    "path": "SKILL.md",
    "old_string": "旧文本",
    "new_string": "新文本",
    "reason": "补充明确的校验步骤"
  }
]
```

典型流程：

```powershell
python -m plugins.daagent.skill_workshop --workspace D:\path\to\workspace snapshot demo-skill
python -m plugins.daagent.skill_workshop --workspace D:\path\to\workspace propose demo-skill --reason '改进校验指引' --patches patches.json
python -m plugins.daagent.skill_workshop --workspace D:\path\to\workspace accept <proposal_id>
python -m plugins.daagent.skill_workshop --workspace D:\path\to\workspace test <proposal_id>
python -m plugins.daagent.skill_workshop --workspace D:\path\to\workspace apply <proposal_id>
python -m plugins.daagent.skill_workshop --workspace D:\path\to\workspace versions demo-skill
```

## 与 DAAgent 原实现的边界

当前版本只实现本地核心闭环，尚未接入：

- Electron/Vue 前端
- GTS Skill Hub、OAuth 和远端发布
- DAAgent 宿主会话轨迹自动采集
- 真实 LLM 诊断和提案生成
- 多用户审批、通知和 host-effect 服务
- 自动轨迹聚类与技能沉淀服务

这些部分可以在核心接口稳定后分别接入，不应把远端市场和本地技能版本库混在一起。
